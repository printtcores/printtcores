# 🎨 Printt Cores — Gráfica & Estúdio de Impressão Premium em Salvador

> **Website Institucional & Plataforma de Conversão (CRO / SEO / UX / UI)**

Bem-vindo ao repositório oficial da **Printt Cores**, estúdio de impressão digital e comunicação visual localizado no **Apipema Center (Ondina, Salvador - BA)**.

Para conferir a documentação técnica completa da aplicação, consulte o arquivo [DOCUMENTATION.md](DOCUMENTATION.md).

---

## 🚀 Teconologias Utilizadas

- **Framework**: [Astro 5](https://astro.build/)
- **Linguagem**: TypeScript
- **Estilização**: Sass (SCSS Modular)
- **Animações**: GSAP (ScrollTrigger) & Anime.js v4
- **SEO & Microdados**: JSON-LD Schema.org (`PrintShop`)

---

## 💻 Como Rodar o Projeto

```bash
# Instalar dependências
npm install

# Rodar em modo de desenvolvimento
npm run dev

# Compilar para produção
npm run build
```
